put this folder /custom on your sd.

it should look like this (without the required jar and elf files)

```text
sd/
└── custom/
    └── greenmenu/
        ├── carplay-vc.esd
        └── scripts/
            ├── cpvc_activate.sh
            ├── cpvc_activate_debug.sh
            ├── cpvc_common.sh
            ├── cpvc_copy_logs.sh
            ├── cpvc_deactivate.sh
            └── cpvc_status.sh
```
